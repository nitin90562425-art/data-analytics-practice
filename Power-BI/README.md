# Mobile Sales Dashboard

## Project Overview
An interactive Power BI dashboard designed to analyze mobile phone sales performance.

## Dashboard Features
- Total Sales, Total Quantity, Transactions and Average KPI cards
- Daily sales trend analysis
- Geographic sales visualization
- Sales comparison by mobile model
- Payment method analysis
- Customer ratings analysis
- Filters for month, mobile model, payment method and brand

## Tools Used
- Microsoft Power BI Desktop
- Power Query
- DAX (if used in the project)
