# Corporate Data Analyzer

## Project Overview
Corporate Data Analyzer is a Python desktop application designed to analyze CSV and Excel datasets through a graphical user interface.

## Features
- Import CSV and Excel files
- Display dataset rows, columns, and column names
- Group data by selected columns
- Perform sum, average, minimum, maximum, median, and count operations
- Preview reports in the application
- Export reports to CSV and Excel
- Create bar, column, line, and pie charts
- Export charts as PNG images

## Technologies Used
- Python
- Tkinter and ttk
- Pandas
- Matplotlib
- PyInstaller

## How to Run
1. Install Python.
2. Install the required packages: `pandas`, `matplotlib`, and `openpyxl`.
3. Run the Python source file:
   `python corporate_data_analyzer_v3(1).py`

## Project Purpose
To make basic data analysis and reporting easier for users who work with CSV and Excel files without needing to write SQL queries or Python code themselves.
