# Indian E-commerce Sales Dashboard

## Project Overview
An interactive E-commerce Sales Dashboard built using HTML, CSS, and JavaScript. It helps users analyse sales performance using Excel data.

## Key Features
- Upload Excel workbook (.xlsx)
- Track Revenue, Profit, Orders and Units Sold
- Analyse monthly sales trends
- View sales by Category, Region and State
- Interactive filters and charts
- Search sales records
- Export filtered data to CSV

## Technologies Used
- HTML
- CSS
- JavaScript
- Microsoft Excel

## How to Run
1. Download the HTML file.
2. Open it in Google Chrome or Microsoft Edge.
3. Upload an Excel workbook containing a sheet named `Sales Data`.
4. Explore the dashboard using filters and charts.
