# Online Bookstore SQL Project

## Project Overview
This project uses SQL and PostgreSQL to manage and analyze an online bookstore database.

## Database Tables
- Books
- Customers
- Orders

## SQL Concepts Used
- SELECT and WHERE
- ORDER BY and DISTINCT
- Aggregate Functions: SUM, AVG, COUNT
- GROUP BY and HAVING
- JOINs
- Subqueries and Advanced Queries
- Sales and Revenue Analysis
- Customer Purchase Analysis
- Book Stock Analysis

## Tools Used
- PostgreSQL
- pgAdmin / SQL Editor

## Project Objectives
- Analyze book sales and revenue.
- Identify frequently ordered books.
- Find customers with multiple orders.
- Calculate books sold by genre and author.
- Analyze customer spending.
- Review remaining book stock.

## Learning Outcomes
This project demonstrates practical SQL querying, relational database concepts, and data analysis skills.
